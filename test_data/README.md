# Test data

- `ZPrf_Grundlagen_der_Informationstechnik_B_Sc_WiIng_ET_IT_WiSe_23_24_TestData.pdf` — the one
  real (anonymized) sample registration export provided by the user. 2 rows, 1 page — build the
  parser against this first, but note it does **not** exercise multi-page parsing or the §5.3
  row-count checksum.
- `registration_synthetic_*.pdf` — five synthetic, anonymized fixtures covering multi-page
  parsing and the §5.3 validation error paths that the real sample can't exercise (multi-page
  continuity, a second course for the same exam sitting, a duplicate Matrikelnummer across
  files, a `Nr.` gap, and a dropped page). Generated by
  `/backend/scripts/make_fixtures.py` — see `/backend/scripts/README.md` for what each one
  covers and how to regenerate them. They're committed (not regenerated by tests) so the test
  suite doesn't depend on a Typst toolchain.

**Only anonymized/synthetic PDFs belong in this directory.** The root `.gitignore` blocks any
`*.pdf` here except the real sample above and anything matching `*_synthetic*.pdf`, so a real
(non-anonymized) export dropped in for local debugging is never accidentally committed.
